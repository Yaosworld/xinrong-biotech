## 三、认证系统

### 3.1 认证流程

```
┌─────────────────────────────────────────────────────────────────────┐
│                           登录认证流程                               │
└─────────────────────────────────────────────────────────────────────┘

   ┌─────────────┐     ┌─────────────────┐     ┌─────────────────┐
   │ 用户输入    │ ──▶ │ POST /api/auth  │ ──▶ │ authService     │
   │ 用户名密码  │     │ /login          │     │ .login()        │
   └─────────────┘     └─────────────────┘     └─────────────────┘
                                                       │
                              ┌─────────────────────────┼─────────────────────────┐
                              │                         │                         │
                              ▼                         ▼                         ▼
                       ┌─────────────┐          ┌─────────────┐          ┌─────────────┐
                       │ 用户不存在  │          │ 账号被禁用  │          │ 账号被锁定  │
                       │ 返回错误    │          │ 返回错误    │          │ 返回错误    │
                       └─────────────┘          └─────────────┘          └─────────────┘
                                                       │
                                                       ▼
                                               ┌─────────────────┐
                                               │ bcrypt.compare  │
                                               │ 验证密码        │
                                               └─────────────────┘
                                                       │
                              ┌─────────────────────────┼─────────────────────────┐
                              │                         │                         │
                              ▼                         ▼                         │
                       ┌─────────────┐          ┌─────────────────┐               │
                       │ 密码错误    │          │ 密码正确        │               │
                       │ 增加失败次数│          │ 生成JWT Token   │               │
                       │ 达到5次锁定 │          │ 更新登录时间    │               │
                       └─────────────┘          │ 返回Token+用户  │               │
                                                └─────────────────┘               │
```

### 3.2 JWT Token

```typescript
// Token 生成
const token = jwt.sign(
  { userId: user.id, username: user.username, role: user.role },
  JWT_SECRET,
  { expiresIn: '24h' }
)

// Token 验证（中间件）
export const authenticate = (req, res, next) => {
  const authHeader = req.headers.authorization
  if (!authHeader?.startsWith('Bearer ')) {
    return res.status(401).json({ error: '未提供认证令牌' })
  }
  
  const token = authHeader.substring(7)
  const decoded = jwt.verify(token, JWT_SECRET)
  req.user = decoded
  next()
}
```

### 3.3 登录安全机制

| 机制 | 配置 | 说明 |
|------|------|------|
| 密码加密 | bcrypt (10轮) | 安全哈希存储 |
| 登录失败锁定 | 5次失败锁定15分钟 | 防止暴力破解 |
| Token过期 | 24小时 | 自动失效 |
| 密码强度 | 8-20位，含字母和数字 | 强制要求 |

### 6.3 数据加载（带降级）

```typescript
async function loadSiteConfig() {
  if (loaded.value) return true

  loading.value = true
  error.value = null

  try {
    // 优先从 API 加载
    const data = await contentApi.getPublishedOne<any>('site_config', 'main')
    
    if (data.company) company.value = data.company
    if (data.contact) contact.value = data.contact
    if (data.friendLinks) friendLinks.value = data.friendLinks
    if (data.footerLinks) footerLinks.value = data.footerLinks
    if (data.floatingPanel) floatingPanel.value = data.floatingPanel
    
    loaded.value = true
    return true
  } catch (e) {
    // API 失败时降级到静态 JSON
    console.warn('API 加载失败，降级到静态 JSON:', e)
    try {
      const response = await fetch('/data/site-config.json')
      if (response.ok) {
        const data = await response.json()
        // 更新状态...
        loaded.value = true
        return true
      }
    } catch {
      error.value = '加载网站配置失败'
    }
    return false
  } finally {
    loading.value = false
  }
}
```

**数据获取逻辑：**

```typescript
// 热门产品（前8个）
const featuredProducts = computed(() => {
  const allProducts = [...productStore.products]
  // 应用排序
  switch (productStore.sortBy) {
    case 'name-asc':
      allProducts.sort((a, b) => a.name.localeCompare(b.name, 'zh-CN'))
      break
    case 'name-desc':
      allProducts.sort((a, b) => b.name.localeCompare(a.name, 'zh-CN'))
      break
  }
  return allProducts.slice(0, 8)
})

// 推荐品牌（自有品牌优先，然后国外品牌，共10个）
const featuredBrands = computed(() => {
  const ownBrands = brandStore.ownBrands
  const internationalBrands = brandStore.brands.filter(brand =>
    brand.is_own_brand !== true && brand.country !== '中国'
  )
  const combinedBrands = [...ownBrands, ...internationalBrands]
  
  if (combinedBrands.length < 10) {
    const domesticAgentBrands = brandStore.brands.filter(brand =>
      brand.is_own_brand !== true && brand.country === '中国'
    )
    combinedBrands.push(...domesticAgentBrands)
  }
  
  combinedBrands.sort((a, b) => (a.sort_order || 999) - (b.sort_order || 999))
```

```typescript
    await authStore.init()
```

```typescript
// 认证中间件
export const authenticate = (req, res, next) => {
  const authHeader = req.headers.authorization
  if (!authHeader?.startsWith('Bearer ')) {
    return res.status(401).json({ error: '未提供认证令牌' })
  }
  
  try {
    const token = authHeader.substring(7)
    const decoded = jwt.verify(token, JWT_SECRET)
    req.user = decoded
    next()
  } catch {
    return res.status(401).json({ error: '无效的认证令牌' })
  }
}

// 超级管理员权限中间件
export const requireSuperAdmin = (req, res, next) => {
  if (req.user?.role !== 'super_admin') {
    return res.status(403).json({ error: '需要超级管理员权限' })
  }
  next()
}
```

## 十四、代码问题分析

### 14.1 现有问题

| 问题 | 描述 | 建议 |
|------|------|------|
| 首页轮播图硬编码 | 图片路径写死在组件中 | 可改为从配置或API加载 |
| 导航菜单硬编码 | 导航项写死在组件中 | 可改为从配置加载 |
| 无记住登录 | 每次关闭浏览器需重新登录 | 可添加"记住我"功能 |
| 无操作日志查看 | 日志只能通过数据库查看 | 可添加日志查看页面 |

### 14.2 潜在风险

1. **Token存储**
   - 当前使用 localStorage 存储 Token
   - 存在 XSS 攻击风险
   - 建议：可考虑使用 HttpOnly Cookie

2. **密码重置**
   - 当前只能由超级管理员重置
   - 无自助找回密码功能
   - 建议：可添加邮箱验证找回

3. **并发编辑**
   - 多人同时编辑网站配置可能冲突
   - 建议：添加编辑锁或版本冲突检测
